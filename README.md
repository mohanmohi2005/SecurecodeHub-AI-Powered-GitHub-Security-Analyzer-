# 🔒 SecureCodeHub+

AI-Powered Secure Code Analysis Platform

SecureCodeHub+ is a web-based application that analyzes source code for security vulnerabilities, coding issues, and best practice violations. It helps developers identify potential risks and provides recommendations to improve code quality and security.

---

## 🚀 Features

- 🔍 AI-powered code analysis
- 🛡️ Security vulnerability detection
- 📄 Detailed security reports
- 💡 Secure coding recommendations
- 📂 Source code upload
- 📊 Scan history management
- 👤 User authentication
- 📱 Responsive user interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/SecureCodeHub.git
```

### Navigate to Project

```bash
cd SecureCodeHub
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

### Run the Application

```bash
npm start
```

---

## 📌 How It Works

1. Upload source code.
2. Backend processes the uploaded files.
3. AI analyzes the code.
4. Vulnerabilities are detected.
5. Security report is generated.
6. Results are displayed to the user.
